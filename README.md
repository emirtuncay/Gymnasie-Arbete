# Gymnasie-Arbete

<h1>Fitness Tracker</h1>

<p>Vår projekt är en app som är webbaserad där användare kan logga sina träningspass, övningar och sets för att följa sin styrketränings utveckling över tid.</p>

## Teknisk stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Databas:** MySQL
